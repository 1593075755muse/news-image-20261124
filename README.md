A program that draws a newspaper-style infographic summing up the world news of Tuesday 24 November 2026: the COP31 climate talks collapsing in Antalya, Ukraine sinking a Russian warship off Libya, Nvidia bringing back Jensen Huang as CEO, sea mines hitting oil tankers in the Strait of Hormuz, US states suing Musk firms over Grok-made images, and more. Pure Python 3 standard library, no network, no dependencies: a small 5x7 bitmap font, simple shape drawing, and a minimal PNG encoder.
